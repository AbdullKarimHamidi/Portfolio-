# Karim Hamidi — Software Engineer Portfolio

A motion-led portfolio built with React, Vite, Framer Motion and a custom dark design system.

## What it presents

- Full-stack engineering and applied computer-vision work.
- 18 projects discovered in the connected GitHub repositories.
- Featured products, smaller builds and technical experiments separated by status.
- Custom SVG project artwork for each project. These are explanatory illustrations, not fabricated screenshots of running products.
- CV-based experience, education, languages and technical skills.
- Responsive layout, animated section reveals, project filtering, 3D card interaction and accessible project-detail dialogs.

## Project accuracy

Project descriptions are grounded in the available repository descriptions, READMEs and source files. Early builds and starter repositories are explicitly labelled as such. Private repositories remain private and their links require GitHub access.

## Stack

- React 19
- Vite
- Framer Motion
- Tailwind CSS 4
- Lucide React

## Development

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```
